# Amazing Frog Skate

A skateboarding mod for Amazing Frog? powered by Skate 3 mechanics.

## Features

- Skateboarding, tricks, manuals, and grinds
- Trick scoring and replay editor
- Custom Skate Park map
- Session markers
- Weapon support while skating
- Controller support and adjustable FOV

## Requirements

- Windows 10 or 11, 64-bit
- An unmodified Amazing Frog Legacy installation
- Skate 3 Xbox 360 files: `default.xex` and its complete `data` folder
- Internet access during initial setup

Game files are not included.

## Installation

1. Download the installer ZIP from [Releases](../../releases).
2. Extract the entire ZIP.
3. Run `Setup Amazing Frog Skate.exe`.
4. Select your Amazing Frog Legacy folder and Skate 3 `default.xex`.
5. Choose a new or empty installation folder.
6. Click **Install**, then **Play** when setup finishes.

Keep the `_internal` folder beside the setup executable. The installer creates a separate game copy and leaves your original games untouched.

## Controls

| Action | Control |
|---|---|
| Toggle skate mode | Both thumbsticks / J |
| Push | A / X |
| Steer | Left stick |
| Tricks | Right stick |
| Get on/off the board | Y |
| Brake | B |
| Grab | Triggers |
| Session markers and replay | Hold LB |
| Aim and fire an equipped gun | Hold RB |
| Reload | RB + X |
| Options | Controller View / F2 |
| Toggle help HUD | F8 |
| Toggle grind guide | F10 |

Weapons activate through the Phone-G Guns menu.

## Known Issues

This mod is experimental. Weapon poses, board-carry animations, and some interactions may still look or behave incorrectly.
